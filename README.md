# 大画幅移轴对焦工作台

本机运行的大画幅相机移轴几何工作台：Python + Flask 计算相机几何，SQLite
保存方案，原生 HTML/CSS/JavaScript + SVG 绘制可拖动的俯视图与侧视图。

## 启动

```bash
pip install -r requirements.txt   # 或使用已建好的 .venv
python3 app.py
# 浏览器打开 http://127.0.0.1:5000
```

- 几何内核自检：`python3 camera_geometry.py --selftest`
- 单元式校验：`python3 test_geometry.py`

## 几何模型（单位 mm）

- 坐标系：`x` 指向被摄体，`y` 指向相机右侧（画面左侧），`z` 向上。
- 前组（镜头）与后组（片盒）各有 5 个自由度：轨道 x、俯仰 tilt、摇摆 swing、
  升降 rise、平移 shift；框架由两次定轴旋转（先绕世界 y 俯仰、再绕世界 z 摇摆）生成。
- 薄透镜 + 主光线 homography：`X' = F + f/(f-d)(Q-F)`，`d=(Q-F)·n_L`，
  像面位于镜头 −n_L 一侧。片平面的共轭即 Scheimpflug 焦平面，代码用
  后组坐标系数 `(f+cx·bx, cx·by, cx·bz) = f·cx` 表示。
- 景深楔形：片平面沿法线平移 `±coc·N_e` 后分别求共轭近/远平面。
- 虚焦圆：以真实像点为锥顶、光圈圆为截面的光锥与片平面求交，取最大跨度。
- 铰链线：后组坐标 `qx=0 且 b·q=f`。

## 功能

- 输入片幅、焦距、光圈、镜头像场、皮腔伸缩范围、轨道/角度/位移限位；
  添加若干主体平面对焦点与构图点。
- 双视图实时绘制：前/后组板、皮腔、镜头光轴与像场锥、Scheimpflug 焦平面、
  铰链线（倾斜时）、景深楔形、片幅角点。
- 在 SVG 上直接拖动：拖对焦点改坐标；拖前组水平=轨道（松手自动重对焦），
  垂直=俯仰/摇摆，Shift+垂直=升降/平移。侧视图控高度方向，俯视图控水平方向。
- 机械与光学检查：轨道行程、皮腔压缩/拉伸、前后组板件碰撞（网格最小间距）、
  像场遮角、对焦误差、构图越界；点击警告高亮并定位相关机件、切换到对应微调页。
- 锁定机位 / 构图边界 / 任意调整量后搜索覆盖对焦点的组合，按最大虚焦量、
  硬警告数、像场余量、调整幅度排序；候选可叠加为虚线焦平面比较，也可一键采用。
- 方案以 SQLite（`workbench.db`）保存/载入/删除。
- 采用方案后生成带刻度的现场调整卡（新窗口，可打印），刻度含 0 位与限位范围。

## 文件

- `camera_geometry.py` 几何内核（框架、共轭平面、自动对焦、虚焦圆、楔形、
  碰撞、像场、构造求解、组合搜索）。
- `app.py` Flask 入口与 SQLite 存储，REST：`/api/compute`、`/api/search`、
  `/api/plans`。
- `static/index.html`、`static/style.css`、`static/app.js` 前端。
