# 大画幅移轴对焦工作台

本机运行的大画幅相机移轴几何工作台：Python + Flask 计算相机几何，SQLite
保存方案，原生 HTML/CSS/JavaScript + SVG 绘制可拖动的俯视图与侧视图。

## 启动

```bash
pip install -r requirements.txt   # 或使用已建好的 .venv
python3 app.py
# 浏览器打开 http://127.0.0.1:5000
```

- 几何内核自检：`python3 camera_geometry.py --selftest`
- 单元式校验：`python3 test_geometry.py`

## 几何模型（单位 mm）

- 坐标系：`x` 指向被摄体，`y` 指向相机右侧（画面左侧），`z` 向上。
- 前组（镜头）与后组（片盒）各有 5 个自由度：轨道 x、俯仰 tilt、摇摆 swing、
  升降 rise、平移 shift；框架由两次定轴旋转（先绕世界 y 俯仰、再绕世界 z 摇摆）生成。
- 薄透镜 + 主光线 homography：`X' = F + f/(f-d)(Q-F)`，`d=(Q-F)·n_L`，
  像面位于镜头 −n_L 一侧。片平面的共轭即 Scheimpflug 焦平面，代码用
  后组坐标系数 `(f+cx·bx, cx·by, cx·bz) = f·cx` 表示。
- 景深楔形：片平面沿法线平移 `±coc·N_e` 后分别求共轭近/远平面。
- 虚焦圆：以真实像点为锥顶、光圈圆为截面的光锥与片平面求交，取最大跨度。
- 铰链线：后组坐标 `qx=0 且 b·q=f`。

## 功能

- 输入片幅、焦距、光圈、镜头像场、皮腔伸缩范围、轨道/角度/位移限位；
  添加若干主体平面对焦点与构图点。
- 在侧视图/俯视图上勾画主体：竖线（侧视）、横线（俯视）、竖直矩形立面、
  必留边界；端点与整条折线都可直接拖动，两视图坐标联动（竖线保持 x/y 相同、
  横线保持等高）。
- 毛玻璃倒像：片平面薄透镜投影随相机位姿实时更新，显示片幅框、留边框、
  像场圈（倾角时为椭圆）、主体倒像与对焦点；可切换正/倒像显示。
- 毛玻璃按主体给出：裁切（含虚像）、竖线汇聚、横线倾斜、梯形畸变、
  边缘放大率差、到片幅边缘的裁切余量；点选异常项回到对应主体（列表/视图/毛玻璃联动）。
- 可设置留边（片上 mm）与透视容差（角度°，同时作为梯形/放大率差的 % 阈值）。
- 双视图实时绘制：前/后组板、皮腔、镜头光轴与像场锥、Scheimpflug 焦平面、
  铰链线（倾斜时）、景深楔形、片幅角点。
- 在 SVG 上直接拖动：拖对焦点改坐标；拖前组水平=轨道（松手自动重对焦），
  垂直=俯仰/摇摆，Shift+垂直=升降/平移。侧视图控高度方向，俯视图控水平方向。
  拖动主体端点或前/后组时，毛玻璃倒像、片幅框与像场圈同步更新。
- 机械与光学检查：轨道行程、皮腔压缩/拉伸、前后组板件碰撞（网格最小间距）、
  像场遮角、对焦误差、构图越界；点击警告高亮并定位相关机件、切换到对应微调页。
- 锁定机位（前后组轨道总开关）/ 焦平面 / 构图边界 / 任意调整量后搜索覆盖对焦点
  的组合，排序依次为：越界项（硬警告+必留边界裁切/留边违规）、最大透视误差、
  裁切余量（大者优先）、调整幅度；候选可叠加为虚线焦平面比较，也可一键采用。
- 方案以 SQLite（`workbench.db`）保存/载入/删除，状态含主体几何，
  摘要含最大透视误差/裁切余量等构图指标。
- 采用方案后生成带刻度的现场调整卡（新窗口，可打印），刻度含 0 位与限位范围，
  卡上附片内边界示意：片幅框、留边框、像场圈椭圆与必留边界倒像，以及逐对象指标。

## 曝光测算单

以一次机位拍摄为对象，按 草稿 → 已确认 → 已拍摄 流转；头部「📸 曝光」进入。

- 建单时从已保存方案（或当前工作台状态）冻结片幅、焦距、光圈和前后组位姿；
  录入测光值（EV@ISO100 或入射 lux）、胶片 ISO、滤镜倍率、快门档位（可勾选）、
  光圈步进（1/3、1/2、1 档）及胶片倒易律曲线（预设或自定义点列）。
- 按当前皮腔伸长和放大率计算皮腔补偿 `(伸长/焦距)²`，叠加滤镜倍率，
  不动点迭代求解倒易律修正后的实际曝光 `t = t₀·factor(t)`（曲线 log-log 插值）。
- 列出全部等效快门—光圈组合（含各档倒易律修正、快门匹配偏差与景深复核），
  点击选用；超出快门范围、倒易律曲线范围或调整光圈后景深点越界时，
  警告可点击定位对应参数（刻度尺/表单高亮）和对焦点（楔形图/毛玻璃闪烁）。
- 摄影师可锁定快门（反算精确光圈并吸附步进档）或锁定光圈（手动组合报偏差），
  设置最长曝光、包围级数和级差；拖动快门/光圈刻度即时比较景深楔形、
  最大模糊圆和总曝光，曝光时间轴展示 测光→皮腔/滤镜→倒易律→实际 修正链路。
- 确认后冻结来源方案、修正项和选定组合；已拍摄单只读，复制为新草稿后才能调整。

## 文件

- `camera_geometry.py` 几何内核（框架、共轭平面、自动对焦、虚焦圆、楔形、
  碰撞、像场、构造求解、组合搜索、片平面投影与毛玻璃构图分析）。
- `exposure.py` 曝光内核（测光换算、皮腔/滤镜补偿、倒易律迭代、等效组合、
  锁定反算、包围序列、按光圈重算景深）。
- `app.py` Flask 入口与 SQLite 存储，REST：`/api/compute`、`/api/search`、
  `/api/plans`、`/api/exposure/*`（测算单 CRUD 与状态流转、试算）。
- `static/index.html`、`static/style.css`、`static/app.js` 前端；
  `static/exposure.js` 曝光测算单面板（刻度尺/时间轴/楔形图/毛玻璃联动）。
- 校验：`python3 test_geometry.py`、`python3 test_exposure.py`。
